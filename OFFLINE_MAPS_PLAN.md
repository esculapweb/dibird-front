# Офлайн-карты в DiBird

## Контекст

Промо-блок на сайте (`app/web/templates/web/includes/app_promo.html`) обещал «Дневники, наблюдения и карты офлайн», но офлайн-карт в приложении нет: [MapL.tsx:139](components/Map/MapL.tsx#L139) при отсутствии сети вообще не монтирует `<Map>` и показывает заглушку `map_unavailable_offline`. Тайлы берутся напрямую с публичного `tile.openstreetmap.org` ([constants/config.ts:30](constants/config.ts#L30)) — источника, чья usage policy запрещает систематическую выкачку, то есть кнопку «скачать регион» на нём делать нельзя.

**24.08 обещание с сайта снято** (GROWTH_PLAN.md, 4.2, врезка «Промо не должно обещать несделанного»): все шесть блоков промо говорят теперь только о том, что действительно работает без сети — дневник, наблюдения и просмотренные ранее чек-листы. Это снимает срочность, но не задачу: офлайн-карта остаётся тем, ради чего птицевед и ставит приложение в поле, и как только она появится, обещание можно вернуть — уже честно.

Цель: птицевед в поле без связи видит карту вокруг своих мест — как минимум те области, что уже открывал, и как максимум заранее скачанный регион. Решения по итогам обсуждения: **кэш + скачивание регионов**, **свой tileserver на бэке**, **векторные тайлы**.

## Что уже есть и переиспользуется

- `@maplibre/maplibre-react-native@11.3.6` содержит весь офлайн-API: `OfflineManager.createPack/getPacks/deletePack/invalidatePack`, `setMaximumAmbientCacheSize`, `setTileCountLimit`, события прогресса ([node_modules/.../offline/OfflineManager.ts](node_modules/@maplibre/maplibre-react-native/src/modules/offline/OfflineManager.ts)). Нативный модуль уже слинкован — плагин зарегистрирован в [app.config.js:167](app.config.js#L167).
- Ambient-кэш MapLibre работает «из коробки»: тайлы, отрисованные онлайн, уже лежат в его SQLite. Их просто некому показать из-за офлайн-гейта в `MapL`.
- `distanceKm`, `normalizeDistance`, `roundCoords` в [util/helpers.ts:260-303](util/helpers.ts#L260-L303) — для радиуса и подписей.
- `isConnected` / `subscribeToConnectionChange` в [services/sync/networkStatus.ts](services/sync/networkStatus.ts) — уже используется в `MapL`.
- Паттерны экрана-списка с действиями: `Section`/`Row`/`Divider` внутри [SettingsScreen.tsx](screens/SettingsScreen.tsx); регистрация экрана — `Stack.Screen` в [navigation/AppStack.tsx:314](navigation/AppStack.tsx#L314) + ключ в `AppStackParamList` ([types.ts:1071](types.ts#L1071)).

## Оценка: объём приложения и время установки

**Размер бинарника и скорость установки не меняются вообще** — ни на этапе 1, ни на этапе 2:

- нативная библиотека MapLibre с офлайн-модулем уже в сборке, ничего нового не линкуется;
- в IPA/APK ничего не вшивается — базовую карту мира внутрь приложения не кладём;
- прирост — только JS: сервис-обёртка, хук, экран, строки локализации — **единицы килобайт** в бандле.

Растёт **место на устройстве пользователя после его собственных действий**:

| Что | Занимает |
|---|---|
| Ambient-кэш просмотренного (этап 1), потолок задаём сами | 50 МБ (рекомендую), настраивается |
| Скачанный район 10×10 км, вектор z0–14 (детализация до z20 через overzoom) | ~2–4 МБ |
| 25×25 км | ~10–20 МБ |
| 50×50 км | ~40–80 МБ |
| 100×100 км | ~160–320 МБ |
| Шрифты + спрайты стиля, разово на всё приложение | ~1–3 МБ |

Для сравнения: тот же район 10×10 км **растровыми** тайлами до z16 — 10–15 МБ, до z18 — ~150 МБ. Векторные выигрывают в 3–5 раз и дают детализацию выше по зуму; поэтому и выбраны.

Серверная сторона (это отдельный бюджет, не влияющий на приложение): planetiler-сборка Европы ≈ 15–25 ГБ, планеты ≈ 80–110 ГБ на диске; пересборка из свежего OSM-дампа — часы, раз в месяц-квартал.

## Этап 1. Показывать офлайн то, что уже скачано (без смены источника)

Работает на текущем OSM-растре, политику не нарушает, ценность даёт сразу.

1. **`services/map/offlineMaps.ts`** — новый модуль, тонкая обёртка над `OfflineManager`. Пока только `initOfflineMaps()`: `setMaximumAmbientCacheSize(50 * 1024 * 1024)` и `setTileCountLimit(...)`. Вызвать один раз при старте — рядом с прочей инициализацией в корне приложения (`App.tsx`).
2. **[components/Map/MapL.tsx](components/Map/MapL.tsx)** — снять жёсткий офлайн-гейт:
   - `showFallback` больше не включает `offline`: `<Map>` монтируется всегда, MapLibre сам отдаёт тайлы из кэша;
   - вместо полноэкранной заглушки — неблокирующий бейдж «офлайн, показаны сохранённые области» поверх карты, координаты с копированием остаются;
   - таймаут `MAP_LOAD_TIMEOUT_MS` офлайн не взводить (сейчас `if (offline) return;` — логику сохранить, но она теперь не должна ронять карту в заглушку);
   - `key={retryKey}` и комментарий про «намеренно не завязано на lng/lat» ([MapL.tsx:79-88](components/Map/MapL.tsx#L79-L88)) сохранить — переход online↔offline больше не должен ремонтировать `<Map>`, иначе слетает уже отрисованный кадр.
3. **Строки**: `map_unavailable_offline` меняет роль (текст бейджа), `map_offline_hint` остаётся. Правки в `locales/en.json` + `locales/ru.json`, затем `npm run i18n:extract`.
4. **Тесты**: переписать [components/Map/__tests__/MapL.test.tsx](components/Map/__tests__/MapL.test.tsx) — офлайн теперь рендерит `<Map>` и бейдж, а не заглушку.

**Риск, который надо снять первым (спайк ~час):** MapLibre уважает `Cache-Control` от OSM (обычно ≤7 дней) — нужно проверить на устройстве, отдаёт ли он протухший ambient-ресурс при мёртвой сети. Если нет — этап 1 деградирует до «работает несколько дней», и вся ценность переезжает в этап 2 (в паках срока годности нет).

## Этап 2. Свой tileserver + скачивание регионов

### 2а. Бэкенд (репозиторий `/Users/esculapweb/Py/dibird`, читать его `CLAUDE.md` перед правками)

1. Сборка тайлов: planetiler по OSM-экстракту → `.mbtiles`/`.pmtiles` (схема OpenMapTiles). Начать с одного-двух регионов, где реально сидят пользователи, а не с планеты.
2. Отдача: сервис `martin` (Rust, легче tileserver-gl) отдельным контейнером в `docker/dibird_production` за существующим `nginx-proxy`, вхост по метке — как остальные сервисы. Тайлы иммутабельные, длинный `Cache-Control`, кэш Cloudflare сверху.
3. `style.json` со шрифтами и спрайтами отдаётся тем же хостом. **Это ключевая точка**: и рендер, и `OfflineManager.createPack` должны ссылаться на один и тот же URL стиля, иначе пак скачает не те ресурсы.
4. Перегенерация раз в месяц-квартал; после неё в приложении — `invalidatePack` (докачивает только изменившееся, а не весь регион заново).

### 2б. Приложение

5. **[constants/config.ts](constants/config.ts)**: `mapTileUrl` → `mapStyleUrl` (`https://tiles.dibird.com/style.json`).
6. **[components/Map/MapL.tsx](components/Map/MapL.tsx)**: `mapStyle={Config.mapStyleUrl}` вместо `EMPTY_MAP_STYLE`; блок `<RasterSource id="osmTiles">` удаляется. Декларативные дети (`Images`, `GeoJSONSource` маркера/точности/полигона) остаются, но теперь ложатся поверх полноценного векторного стиля — проверить порядок слоёв, при необходимости явный `belowLayerID`.
7. **`services/map/offlineMaps.ts`** дорастает до полного API: `createRegionPack({ center, radiusKm, name })` (внутри — bounds из центра и радиуса, `minZoom: 0`, `maxZoom: 14`, `metadata: { name, createdAt, center }`), `listPacks()`, `deletePack(id)`, `getTotalSize()`. Ошибки — через `normalizeApiError`/`showErrorToast` по конвенции проекта, без ручного `Sentry.captureException`.
8. **`util/helpers.ts`**: рядом с `distanceKm` — `boundsFromRadius(center: Coords, km: number): LngLatBounds` и форматтер размера (`formatBytes`) — готового в проекте нет.
9. **`hooks/useOfflineMapPacks.ts`**: список паков + подписка на события прогресса/ошибки `OfflineManager`. React Query здесь не нужен — данные локальные, в MapLibre-SQLite; Drizzle-зеркало тоже не нужно, второй источник правды только создаст рассинхрон.
10. **`screens/OfflineMapsScreen.tsx`**: список скачанных районов (имя, размер, состояние, прогресс), удаление, суммарный объём. Регистрация — `Stack.Screen` в [navigation/AppStack.tsx](navigation/AppStack.tsx) + ключ `OfflineMaps: undefined` в `AppStackParamList` ([types.ts:1071](types.ts#L1071)). Вход — новый `Row` в секции `settings_section_data` [SettingsScreen.tsx:328](screens/SettingsScreen.tsx#L328), рядом с экспортом и импортом.
11. **[screens/PlaceDetailScreen.tsx:266](screens/PlaceDetailScreen.tsx#L266)**: под картой — «Скачать карту этого места» с выбором радиуса (5 / 15 / 50 км) и показом ожидаемого объёма до подтверждения. Координаты у места уже есть (`location`), bounds считаются из центра.
12. **i18n**: новые ключи в `locales/en.json` + `locales/ru.json` парой, затем `npm run i18n:extract`. Ключ с `count` (число районов) — сразу всеми формами CLDR, без базового ключа.
13. **Тексты промо на бэке** (`app_promo.html:10` + `django.po`) — сверить с тем, что реально уехало в релиз, и поправить, если этап 2 не успевает.
